 CineComic-MML: Phase 4 and Phase 5 Code
 Complete source: shot/frame pipeline and face detection, tracking and character IDs
Phase 4 - shots, frames, quality
Crops black bars, detects shots, samples frames, removes dark / blurry / near-duplicate frames and builds 3-10
candidate frames per dialogue segment. Writes data/shots/{id}.json and data/frames/{id}/shot_xxx/*.jpg.
Phase 5 - faces, tracks, character IDs
Detects faces on original-resolution frames (about 5 fps inside dialogue windows, plus Phase 4's candidate frames),
embeds them with ArcFace, tracks them inside each shot, then clusters tracks into characters (CHAR_01, ...) with a
cannot-link rule so two people on screen together are never merged. Low-confidence tracks become UNKNOWN.
Reads data/shots/{id}.json and data/subtitles/{id}.json. Writes data/faces/{id}.json, data/embeddings/faces_{id}.npy,
data/tracks/{id}.json.
Install and run
 pip install -r requirements.txt
python -m src.video.phase4 --config configs/phase4.yaml --video clip_001
python -m src.vision.phase5 --config configs/phase5.yaml --video clip_001 --gt faces_gt.json
pytest tests/
Create empty __init__.py in src/, src/video/, src/vision/ and src/evaluation/ before running. Phase 5 labelled-face file format:
{"frames": [{"t": 14.5, "faces": [{"box": [x0,y0,x1,y1], "character": "alice", "frontal": true}]}]}; label every visible face in each labelled
frame, and use frame times that Phase 5 sampled (multiples of 1/det_fps).
Gates (suggested starting values; set your own after the first run)
Phase 4: boundary F1 >= 0.85; coverage 100%; no candidate outside its shot; black-border rate <= 2%; crop IoU >=
0.95.
Phase 5: recall >= 90% on medium/large frontal faces; 0 ID switches inside a shot; cluster purity >= 90%; no track
spans a shot; no two simultaneous tracks share a character_id.
Note: InsightFace model packs are provided for non-commercial research use; check the current licence before relying on them.
